# 작업 일지

**최신이 위.** Phase별 섹션 안에서도 최신 항목이 위로 온다.

## 무엇을 남기는가

- 예상과 다르게 동작한 것 (원인을 알아낸 것도, 아직 모르는 것도)
- 측정 수치 (쿼리 개수, 응답 시간, TPS, 실패율 — 측정 조건을 함께)
- 시도했다가 되돌린 것과 그 이유
- 발견한 함정 (툴·프레임워크의 비직관적 동작, 재현 조건)

## 무엇을 남기지 않는가

- 단순 작업 나열 ("Product 엔티티 작성", "테스트 추가") — `git log`와 중복이다
- 성공적으로 끝나 배울 게 없는 작업
- `DECISIONS.md`에 들어갈 설계 근거 — 그건 결론이고, 여기는 과정이다

## 항목 형식

```markdown
### YYYY-MM-DD 한 줄 제목

**상황** 무엇을 하려던 중이었나
**시도** 무엇을 해봤나
**결과** 무슨 일이 일어났나 (수치가 있으면 수치로)
**배운 것** 다음에 같은 상황에서 무엇을 다르게 할 것인가
```
